# JINIVERSE

진짜 나의 우주를 찾는 16가지 궤도. 70개의 일상 장면으로 성격 유형을 찾는 웹 검사입니다.

- 4축 × 4측면, 70문항 + 경계형 축만 추가로 묻는 적응형 문항(축당 최대 8문항)
- 축별 퍼센트, 선명도, 결정적 근거, 응답 품질, 재검사 일치 추정치 제공
- 16개 측면 점수로 만드는 개인 해석(나의 지문, 숨은 반전), 에너지와 사용 설명서, 기질·결정·갈등 스타일, 16유형 소통 가이드, 7일 성장 미션
- 서버 없이 동작하는 단일 HTML 파일(index.html). 응답은 방문자의 브라우저(localStorage)에만 저장됩니다.

## 폴더 구성

- index.html : 검사 본체
- sim/sim.js : 채점 엔진 검증용 시뮬레이션(가상 응답자 50명 × 20회 = 1,000회)
- sim/sim_report.txt : 시뮬레이션 결과
- sim/personas.json : 가상 응답자 50명 정보

## 시뮬레이션 다시 돌리기

Node.js가 필요합니다.

    cd sim
    node sim.js ../index.html

결과는 sim 폴더의 sim_report.txt와 personas.json에 저장됩니다.

## 알아둘 점

- 기준값(경계 구간, 응답 품질 기준, 재검사 추정표)은 가상 응답 시뮬레이션으로 보정한 잠정 규준입니다. 실제 응답 데이터로 다시 보정해야 합니다.
- 녹녹이 자체 설계한 검사로 The Myers-Briggs Company의 공식 MBTI®와 무관합니다. 자기이해와 재미를 위한 도구이며 진단이나 채용 판단에 쓰지 마세요.
